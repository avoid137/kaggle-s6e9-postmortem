## 第 3 轮：组合器的函数形态是最后一个真杠杆 → 0.94275 → 0.94305

成员集冻结，**只改组合器形态**：

| 组合器 | cross-fit |
|---|---|

**注意这个反差**：同一批原始特征，给 LR 是 −0.0004 ~ −0.0007，给树状元是 **+0.0003** —— "区域门控"的典型指纹。

**但消融推翻了"是原始特征在起作用"**：成员分数单独 0.94301 ≈ +3 信号 0.94303 ≈ +13 原始特征 0.94301 → **增益来自成员分数之间的非线性组合**，不是原始特征。

配置扫描面很平（0.94295–0.94305）→ 不是撞运气。9 元模型秩平均 → **0.94305**。

## 第 4 轮：换成"叶内线性树" → 0.94305 → 0.94313

先量化风险来源：成员矩阵平均 |corr| **OOF 0.9383 vs TEST 0.9519**；列 std 0.9800 vs 0.9849 → test 列**更平滑、彼此更相关**，而树的分裂阈值定在更噪的 OOF 上。**阈值型学习器对这件事最敏感。**

对策：换"平滑的非线性"（保留表达能力、去掉阈值脆弱性）

| 元学习器 | cross-fit（3 seed） |
|---|---|
| **叶内线性树 `linear_tree=True`** | **0.94309**（波动仅 ±1e-5） |
| 纯树 + 聚合统计量 | 0.94304 |
| 纯树元 | 0.94301 |
| 线性 LR 元 | 0.94275 |
| 小型 MLP 元 | 0.94268（欠拟合，比线性还差） |

精调 9 配置全落在 0.94306–0.94311（面同样极平）→ 3 配置 × 2 seed 秩平均 = **0.94313**。

**线性"对冲"不划算**：权重扫描 w·线性 + (1−w)·叶内线性树，**w=0 最优**（0.94313），w=0.5 掉到 0.94306 → 上一轮的 50/50 混合白丢 0.00007。

## 第 5 轮：给元学习器换一组基 → 0.94313 → 0.94320

思路：增益活在成员空间里（"A 说 0.99 而 B 说 0.2 时该信谁"），但 37 个成员列彼此相关 **0.94**，这个结构**不与坐标轴对齐**，树只能轴对齐切分。**显式提供"分歧方向"能让元学习器更省力。**

| 变体 | 3 seed 均值 |
|---|---|
| **+ 前 10 成员的 45 个两两差值** | **0.94314** |
| **+ 3 个主导原始信号** | **0.94313** |
| + PCA 旋转（逐折拟合） | 0.94312 |
| + 聚合统计量 | 0.94311 |
| 纯成员 | 0.94309 |
| + `path_smooth=50` | 0.94308 |

三个结论：① "分歧坐标"确实有效（+0.00005）；② **叶内线性之后，原始特征从"无效"变"有效"**（纯树下 +0.00000，叶内线性下 +0.00005）；③ `path_smooth` 无效 —— 显式平滑叶子不如直接换叶内线性。

组合 M1+M4+M2 → **0.94320**。

## 第 6 轮：正面攻击"分歧坐标"（负结果）

行中心化 `Gc = G − rowmean(G)`，把"某成员高于共识多少"变成可直接分裂的坐标，再加纯分歧表示 / 分歧空间 PCA / 补贴门控分歧。

| 变体 | 3 seed 均值 |
|---|---|
| 成员 + 中心化矩阵 PCA | 0.94314 |
| 成员 + 行中心化 | 0.94313 |
| 纯分歧表示 | 0.94313 |
| 成员 + 两两差值（第 5 轮最优） | 0.94314 |
| 成员 + 门控分歧 | 0.94312 |
| 纯成员 | 0.94309 |

93 个子集穷搜最优 0.94321，仅比冠军高 **1e-5** → 低于 2e-5 停手阈值，**不重写文件**。

结论：**减掉共识和给出两两差值是同一信息的两种写法**，收益不叠加；"门控分歧"反而更差（补贴是硬门，乘 0 会抹掉整个 No 区的信息）；**换基这条线已榨干**。

## 第 7 轮：迁移风险诊断 → 结论"可以放心提交"（**后来被 LB 推翻**）

方法：把 OOF 成员列按比例 λ 向行共识收缩 `(1−λ)G + λ·rowmean(G)`，**数值解出使 OOF mean|corr| 恰好等于 TEST 实测值（0.9519）的 λ=0.12**，再在这个"伪 test 平滑度"矩阵上重跑 cross-fit：

```
base      0.94314
smoothed  0.94313     ← 差 1e-5，打平
```

判定：**风险不成立，非线性元可放心提交**。

**这个判定是错的。** 第 10 轮的 11 份 LB 结果显示非线性元系统性掉分。教训：**复现分布漂移的一个矩（相关系数）不等于复现漂移本身**；当训练与部署表示来自不同流水线时，在训练侧表示上做交叉验证**结构上就无法认证**组合器。

## 致命的坑（按代价排序）

### 1. 贪心融合存了"未归一化的加权和" → 整轮结论作废

`oof_blend2.npy` / `test_blend2.npy` 里 min 0.0006 / max **15.9** / mean 4.64，**51.9% 的值 ≥ 1**。下游 `clip(1e-6, 1-1e-6)` + logit 后，AUC 从 0.9422 崩到 **0.7865**。

后果：我**整轮**把"某成员权重=0、毫无贡献"当作模型的性质，其实那全是尺度假象。修正做法是在**秩高斯化空间**（`norm.ppf(rankdata(a)/(n+1))`）里做一切加权与比较。

**规则**：信任任何融合指标前先 `assert (0<=p).all() and (p<=1).all()`；比较两个候选必须**在同一空间**（都 raw 或都 gauss），绝不能一个 raw 一个 logit。

### 2. 用"家族减法"复现上轮胜者 → 候选集静默变成另一个集合

`newweak` 家族从 4 个名字涨到 6 个，同一个候选表达式于是**静默变成另一个成员集**，导致上轮那个 0.94274 的配置整轮未被重测、所有候选都低于它，差点误判成"新成员有害"。

**修法**：按**显式成员名 pin 住**（`DROP=[...]` 写死）+ 断言成员数 + **开局先重测一次上轮胜者的分数**确认可复现。

### 3. 别名优先级 bug：全量重训的 test 预测被 5 折版静默覆盖

`testfull_*.npy`（100% 数据重训）会被自动发现的 `test_*.npy` 覆盖，导致"全量重训"这个**唯一 CV 测不出**的真实增益被丢弃。**修法**：用 dict 建池、别名**后写覆盖**。

### 4. 元学习器选型本身会过拟合

在同一 cross-fit 上挑最好配置，等于把选择噪声算进分数。对策：看**曲面是否平坦**（本例 0.94295–0.94305 全平）并做 3 seed 验证，而不是只报最优那一格。

### 5. `gauss()` 之后比较 OOF/TEST 分位数 = 自证式通过

秩高斯化会**强制两侧边际分布都是标准正态**，所以每个分位数必然相同 —— 这种"检查"没有任何信息量。**比较分布必须用未变换的原始概率。** 通用教训：**任何"把两边都做同一种归一化后再对比形状"的诊断都是无效的，归一化会抹平你要测的差异。**

### 6. 打印时把"分数"和"预测数组"塞进同一个变量

`f"{np.mean(arr):.5f}"` 会报 `unsupported format string`，或者更糟：把矩阵打印成一大块。**同一个坑犯了两次。** 修法：容器命名自带类型（`aucs[tag]` / `oofs[tag]`），打印前 `assert np.isscalar(x)`。

### 7. 其他

- **`NameError: SEEDS`** 之类"跑到最后一步才炸"的错会白烧十几分钟计算 → 长脚本开头就定义所有全局常量 + 先做语法自查。
- **写"出货函数"时 OOF 与 test 两侧必须分别构造**：PCA 要在**每折内**拟合（OOF 侧）、在**全量**上拟合（test 侧），只写一个 `make(tri, vai)` 会让 test 侧拿到 train 矩阵。
- LightGBM ≥4.7：`predict(X, num_iteration=...)` 必须用关键字，位置参数会被当成别的语义。
- `DataFrame[array]` 是**列选择**不是行选择 → 行索引要用 `.values` / `.iloc`。
- 进程退 `0xC0000142`（DLL init 失败）通常是机器休眠所致，不是代码 bug → 把批处理脚本写成**可续跑**（存在 `oof_*.npy` 就跳过）。

## 结论与剩余方向

1. **公开榜 0.94278，排名 878/1965（≈前 45%）。** 榜首 0.94672。**我试过的所有合法路径都没能补上这 0.004** —— 已系统性证伪线性模型、原始数据集联合训练、标签确定性、NN/RealMLP、高阶交叉目标编码、单调约束、10 折/全量重训、秩平均、CatBoost CTR、4 种 k-NN、生成式 NB、Nystroem-RBF、伪标签。
   - **措辞边界（重要）**：以上只能推出"**我没找到**"，不能推出"**别人不可能**"——榜上确实有人做到了，只是我不知道他们怎么做的。写公开文时只写前者。把"我没找到"写成"不可复现"，既不可证伪、又容易被当成对别人的指控，是这类复盘唯一真正会被挑刺的地方。
2. **本赛不发奖牌、不计积分**（官方页面明写）。
3. **唯一还值得做的技术方向**：把成员 OOF 列改成 **repeated K-fold 同阶聚合**（多 seed，每行取各 replicate 的 out-of-fold 预测平均），使训练侧与部署侧的**聚合阶数一致**，非线性元才有可能真迁移。代价 ×K 训练量，只需对权重最高的 ~10 个成员做。**这是验证一个假设，不是稳赚的 +0.0005** —— 因为原来那个 +0.00048 已被证明是假的，真实的非线性增益可能是 0；线性元自身的上限就在 LB ≈ 0.9428，已经摸到。
